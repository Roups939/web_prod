# Техническое задание на проект: Currency Portfolio Tracker

## 1. Цель проекта
Создание веб-сервиса для учета и аналитики валютных сбережений. Система решает проблему ручного отслеживания курсов валют и расчета прибыли. Пользователь может вести учет своих валютных счетов, фиксировать операции покупки/продажи, а система автоматически подтягивает актуальные курсы из внешнего API и рассчитывает текущую доходность портфеля.

## 2. Роли пользователей
* **Гость:** просмотр общей статистики по курсам валют и публичной аналитики (графики, средние значения).
* **Зарегистрированный пользователь:** создание и управление личными счетами, добавление транзакций (покупка/продажа), просмотр личного дашборда с расчетом прибыли/убытка.
* **Администратор:** управление справочником валют и просмотр всех пользователей через админ-панель Django.

## 3. Модели данных (сущности)

* **Currency (Валюта):**
    * `code` (CharField): Уникальный код валюты (например, USD, EUR).
    * `name` (CharField): Полное название.
    * `current_rate` (DecimalField): Актуальный курс к рублю (обновляется через API).

* **Account (Счет):**
    * `user` (ForeignKey): Владелец счета.
    * `name` (CharField): Название счета (например, «Отпуск»).
    * `currency` (ForeignKey): Валюта счета.
    * `balance` (DecimalField): Текущий баланс (рассчитывается на основе транзакций).

* **Transaction (Транзакция):**
    * `account` (ForeignKey): К какому счету относится.
    * `transaction_type` (CharField с выбором): Тип операции (Покупка/Продажа).
    * `amount` (DecimalField): Количество валюты.
    * `rate_at_moment` (DecimalField): Курс валюты на момент совершения операции.
    * `date` (DateTimeField): Дата операции.

## 4. Ключевой функционал (User Stories)
1. **Дашборд:** Пользователь заходит на сайт и видит общую сумму своих сбережений в рублях, пересчитанную по актуальному курсу.test_test_test
2. **Ведение учета:** Пользователь создает счет «Валютный депозит» в USD и добавляет транзакцию: «Купил 100 USD по курсу 90 руб.».
3. **Анализ:** Система автоматически рассчитывает: «Текущий курс 95 руб. Ваша прибыль составляет 500 руб.».
4. **Визуализация:** На странице валюты отображается график изменения курса за последние 30 дней (данные подтягиваются из API).

## 5. Внешние интеграции и аналитика
* **Интеграция:** Использование открытого API Центробанка РФ (или `exchangerate-api.com`) для получения актуальных курсов валют.
* **Аналитика:** Использование библиотеки `requests` для запросов к API и библиотеки `matplotlib` (или `plotly`) для генерации графиков динамики курса.
