# Currency Portfolio Tracker

Веб-сервис для учета и аналитики валютных сбережений. Позволяет вести учет счетов в разных валютах, автоматически подтягивать актуальные курсы ЦБ РФ и рассчитывать прибыль/убыток по портфелю.

## Демо
Сайт доступен по адресу: [http://138.124.184.36](http://138.124.184.36)

## Стек технологий
*   **Backend:** Python 3.14, Django 5.2
*   **База данных:** MySQL
*   **Frontend:** HTML5, CSS3 (кастомная темная тема), JavaScript (Chart.js для графиков)
*   **Аналитика:** Pandas, Matplotlib (для генерации данных)
*   **Деплой:** Ubuntu 26, Nginx, Gunicorn

## Основные возможности
*   Регистрация и аутентификация пользователей (PBKDF2 хеширование).
*   Создание счетов в любой валюте из справочника ЦБ (54 валюты).
*   Автоматическое подтягивание курса ЦБ на выбранную дату через API.
*   Возможность указать ручной курс (если валюта куплена в обменнике).
*   Расчет текущей прибыли/убытка по каждому счету и по всему портфелю.
*   Построение графиков динамики курса за 30 дней.
*   Защита от SQL-инъекций (Django ORM), CSRF-атак и IDOR (доступ только к своим счетам).

## Установка и запуск (локально)
1. Клонируйте репозиторий:
   `git clone https://github.com/Roups939/web_prod.git`
2. Создайте виртуальное окружение и активируйте его:
   `python -m venv .venv`
   `source .venv/bin/activate` (или `.venv\Scripts\activate` на Windows)
3. Установите зависимости:
   `pip install -r requirements.txt`
4. Создайте файл `.env` в корне проекта (пример в `env.example`).
5. Примените миграции:
   `python manage.py migrate`
6. Загрузите курсы валют:
   `python manage.py fetch_rates`
7. Запустите сервер:
   `python manage.py runserver`
